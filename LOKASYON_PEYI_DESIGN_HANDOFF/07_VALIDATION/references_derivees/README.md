# Repères aux largeurs intermédiaires

Les 18 JPEG sont les premiers écrans de la source HTML pour les trois routes aux largeurs 1280, 1024, 768, 430, 375 et 320. Captures effectuées en Chromium, FR, Guadeloupe, DPR 1. Ces repères dérivés servent au reflow et à la composition. [Mesures](reference-metrics.json). Le script de capture produit leurs PNG et versions pleine page pour comparaison. La revue complète permet également de vérifier les interactions décrites dans la matrice.
