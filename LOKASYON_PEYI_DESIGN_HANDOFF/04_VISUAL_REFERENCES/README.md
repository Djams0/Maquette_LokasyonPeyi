# Revue et captures

Ouvrir [le prototype de revue](maquettes/index.html) depuis le dossier extrait dans un navigateur. Les PNG natifs sont les références de comparaison 1440 et 390. Les états 1280 viennent de la production. Pour d’autres largeurs, la revue HTML permet de générer une référence dérivée. Les dimensions suivantes sont les pixels des fichiers, parfois pleine page. Le protocole précise le viewport de capture.

Paramètres de revue · `?page=accueil`, `?page=catalogue`, `?page=fiche&id=clio`, `?page=verre`, `?profil=owner`, `?profil=renter`. Les liens et données de la revue servent à examiner la mise en page. L’intégration utilise les routes et les règles actuelles du dépôt. Les [crédits](ressources/Credits.html) fonctionnent hors ligne jusqu’au lien vers les sources.
