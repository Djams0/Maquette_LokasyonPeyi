# Références visuelles de l’extension client

Les rendus JPEG B 11–49 sont des pages du PDF à 90 dpi. Les maquettes de B sont composées dans les pages, parfois avec comparaison de deux états. Le PDF est la source la plus précise récupérée. Les JPEG d’exécution ont été capturés à 390 et 1440 sur main, Chromium 141, profils fictifs et instance jetable. Les quatre fichiers parcours proviennent de tests existants et peuvent montrer un état distinct de la planche. Aucun score de conformité de l’extension n’est calculable avant implémentation.
